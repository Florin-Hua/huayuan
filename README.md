## 命名与提交规范

- 阶段进程文件：第X阶段-名称.md，统一存放在 01-阶段进程/
- git 提交信息格式：feat/fix/test/docs(scope): 描述
- 每完成一个阶段固定三件事：写进程文件 → 更新本 README 进度表 → git 提交并推送
- 项目完成后统一推送远程仓库
