# 第5阶段 · 记忆系统

> 日期：2026-10-09
> 状态：代码与单元验收完成；真实验收继续受外部网络/API Key 限制
> 代码位置：`02-代码仓库/mini-agent/`

## 1. 阶段目标

让 MiniAgent 拥有跨会话长期记忆：

1. `MemoryStore`：SQLite 存储记忆正文，sqlite-vec 存储 embedding 并做 KNN 检索；
2. 记忆字段：内容、embedding、来源 run_id、创建时间；
3. `save_memory` 工具：模型可在任务中主动保存事实；
4. 任务结束后自动抽取：用一次 LLM 调用判断是否有值得长期记住的信息；
5. 每次任务开始检索 top-3 相关记忆并注入 system prompt；
6. CLI 支持 `mini memory list / delete / search`；
7. pytest 覆盖写入、检索相关性排序、删除、工具保存、自动抽取与跨会话记忆。

## 3. 核心设计

### 3.1 存储结构

普通表：

```sql
CREATE TABLE memories (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    content TEXT NOT NULL,
    source_run_id TEXT,
    created_at TEXT NOT NULL
)
```

向量虚拟表：

```sql
CREATE VIRTUAL TABLE memory_vectors
USING vec0(embedding float[256])
```

两者通过 `memories.id = memory_vectors.rowid` 关联。删除记忆时同步删除正文和向量。

### 3.2 默认 Embedding

当前默认 `HashingEmbedder`：

- 输入英文/数字词、中文单字与 bigram；
- 用 blake2b 哈希到 256 维；
- L2 归一化后交给 sqlite-vec；
- 完全离线、确定性，适合单测和没有 embedding API 的环境。

已知局限：这是词面哈希向量，不是语义 embedding。验收问题“我导师姓什么”能命中“用户的导师姓张”，因为共享“导师/姓”等词面信号；但同义改写能力有限。后续可以在不改变 MemoryStore 接口的情况下替换为 OpenAI embedding。

### 3.3 检索与注入

任务开始时：

```text
task -> MemoryStore.search(task, top_k=3)
      -> memory_to_message(matches)
      -> AgentCore.run(..., memory=[message])
      -> ContextManager.prepare(history, memory)
```

注入顺序：

```text
system prompt
长期记忆 system message
current user input
ReAct history
```

第4阶段的压缩逻辑保持不变；如果上下文超预算，memory 仍位于摘要之前。

### 3.4 主动保存工具

`save_memory(content: str)` 由 `create_save_memory_tool(memory_store)` 动态生成：

- 绑定当前 Agent 的 MemoryStore；
- 注册进 ToolRegistry，模型可通过 function calling 调用；
- 返回 `{id, content, saved}`；
- source_run_id 标记为 `model-tool`。

工具在线程池中执行，SQLite 连接使用 `check_same_thread=False`，保证工具线程可以写入。

### 3.5 任务后自动抽取

任务成功后，Agent 额外调用一次当前 ChatAdapter：

```json
{"save": true, "memories": ["用户的导师姓张"]}
```

解析规则：

- 支持裸 JSON 与 ```json 代码块；
- `save=false` 时不写入；
- 每条记忆必须是非空字符串；
- 保存后写入 `AgentRun.memories_saved`；
- 抽取失败不影响主任务成功状态。

## 4. 配置方式

`.env`：

```env
MEMORY_ENABLED=true
MEMORY_DB_PATH=data/memory.sqlite3
MEMORY_TOP_K=3

```

```powershell

```

## 6. 关键决策

| 决策 | 选择 | 理由 |
|---|---|---|
| 存储 | SQLite + sqlite-vec | 单文件部署，无需外部向量数据库；面试时可讲清向量检索落地 |
| 默认向量 | 本地 HashingEmbedder | 测试离线可复现；真实语义 embedding 可后续替换 |
| 记忆注入 | system message | 与第4阶段注入顺序兼容，模型优先级高且 provider 无关 |
| 主动保存 | 动态生成工具 | save_memory 绑定当前 store，不引入全局状态 |
| 自动抽取 | 复用 ChatAdapter | 不新增模型配置；OpenAI/Anthropic 适配自动复用 |
| 抽取失败 | 不影响主任务 | 记忆是增强能力，不应让已完成任务变成失败 |
